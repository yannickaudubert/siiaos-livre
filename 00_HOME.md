## Architecture éditoriale

Le livre est maintenu comme un système de connaissances versionné. Une idée peut être présente sous quatre statuts distincts : **observation**, **hypothèse**, **modèle/doctrine**, **fait sourcé**.

Une formulation ne devient pas plus vraie parce qu'elle est répétée dans plusieurs notes. Chaque affirmation importante doit pouvoir revenir à sa provenance.

## Chaînes canoniques

**Capacité** : Intelligence → Mémoire → Action → Gouvernance

**Connaissance** : Trace → Fragment → Indice → Hypothèse → Concept → Relation → Méthode → Skill → Agent → Livrable → Commun

**Transformation** : Observer → Comprendre → Expérimenter → Mesurer → Documenter → Corriger → Transmettre → Recommencer

**Créativité gouvernée** : Éveil → Divergence → Rêve → Oracle → Contrefactuel → Adversarial → Retour au réel

## Règle de continuité

Le manuscrit ne remplace pas les travaux antérieurs. Il les absorbe, les critique, les versionne et conserve les divergences utiles. Les concepts écartés restent accessibles par Git et par le journal de recherche.
